# Visual review captures

The screenshots in this folder are generated by `capture-review.mjs` using Playwright and the local mock-only prototype.

## Capture

From `prototype/interface`:

```bash
npm install
npx playwright install chromium
npm run check
npm run screenshots
```

The capture script writes to `review/screenshots/`. It captures Home, Work, Conversation, Original and Working Workbench modes, Model Context, an AI-generated child artifact, Browser Session, Prompts, Notes, Command Palette, and responsive views at 1280 × 800, 1024 × 768, and 900 × 700. Responsive runs check horizontal overflow and exercise the primary navigation.

Screenshots use mock content only; they do not show live provider accounts or real data. A screenshot proves only the displayed state at its named viewport. It does not prove Electron runtime, provider capture, persistence, or production services.
